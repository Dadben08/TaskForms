Task Management App
📘 Description

A simple task management app where users can add and view tasks. It includes user authentication and connects the frontend to a backend for data storage.

⚙️ Features

Add new tasks

View all tasks

User login and registration

Secure backend with JWT

Connected frontend and backend using Axios

🧩 Challenges

Authentication: Solved by using JWT tokens.

Frontend-backend connection: Fixed with Axios and proper API routes.

Form validation: Added checks to ensure all fields are filled before submission.
